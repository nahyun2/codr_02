# 넌센스 퀴즈 게임

터미널에서 동작하는 넌센스 퀴즈 게임입니다.

## 프로젝트 개요

터미널에서 실행하는 넌센스 퀴즈 게임입니다. 메뉴에서 번호를 선택해 퀴즈를 풀고, 새 퀴즈를 직접 추가하고, 등록된 퀴즈 목록과 최고 점수를 확인할 수 있습니다. 진행 상황(퀴즈 목록, 최고 점수)은 `state.json`에 저장되어 프로그램을 종료했다가 다시 실행해도 유지됩니다.

## 퀴즈 주제 및 선정 이유

주제: 넌센스 퀴즈

선정 이유 : 부담 없이 재밌게 문제를 풀어보시도록 하기 위함입니다.

## 실행 방법

Python 3.10 이상이 필요합니다. (외부 라이브러리 설치 없이 표준 라이브러리만 사용)

```bash
python --version
python main.py
```

## 기능 목록

- 퀴즈 풀기 (매번 랜덤 순서로 출제, 정답 대신 `0`을 입력하면 힌트 확인 가능)
- 퀴즈 추가 (힌트 입력 선택 가능)
- 퀴즈 목록 확인
- 점수 확인
- 퀴즈 삭제
- 종료

## 데이터 파일 설명 (state.json)

프로젝트 루트에 UTF-8로 저장되는 JSON 파일로, 퀴즈를 추가하거나 최고 점수를 갱신할 때 자동으로 저장됩니다. 파일이 없거나 손상된 경우 기본 퀴즈 5개로 자동 복구됩니다.

```json
{
  "quizzes": [
    {
      "question": "질문 문자열",
      "choices": ["선택1", "선택2", "선택3", "선택4"],
      "answer": 1,
      "hint": "힌트 문자열 (없으면 빈 문자열)"
    }
  ],
  "best_score": 0
}
```

- `quizzes`: 등록된 퀴즈 목록. 각 항목은 `question`(문제), `choices`(선택지 목록), `answer`(정답 번호, `choices`의 1부터 시작하는 인덱스), `hint`(힌트, 선택 사항)로 구성됩니다.
- `best_score`: 지금까지 기록된 최고 점수(맞힌 문제 수)입니다.
